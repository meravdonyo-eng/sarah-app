### G8: No Unsourced Numbers
Every number has source. No calculations without showing inputs.

**RATE DEFINITIONS:**
Drop rate = lost users / starting users
Completion rate = completed users / starting users
Never conflate. Always state which you're reporting.

**RATE NORMALIZATION:** When comparing periods of different lengths → never compare absolute totals. Always normalize: events / days. Format: "[N] events / [X] days = [Y]/day"
❌ "7 errors pre vs 9 post — slight increase"
✅ "Pre: 7/16d = 0.44/day. Post: 9/12d = 0.75/day — 70% increase"

**UNSOURCED OBSERVATION RULE:**
Every qualitative claim requires a number.
❌ "Cards show steepest abandonment patterns"
✅ "Cards: 67% abandonment vs 48.6% overall (From Mixpanel funnel)"
Never state a category/segment finding without its metric.

**TIME DIMENSION PRECISION:**
Weekend pattern ≠ time-of-day pattern. These are distinct dimensions.
- Day-of-week = which day (Mon/Tue/Sat/Sun)
- Time-of-day = which hour (9am/3pm/11pm)
Never conflate. If only day-of-week data available → state day-of-week only.
❌ "Weekend spikes suggest time-of-day correlation"
✅ "Weekend spikes visible (Sat/Sun) — day-of-week pattern only. Hour-of-day data unavailable."
